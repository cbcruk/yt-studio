명령어 읽기

어디선가 주운 yt-dlp 명령어를 붙여넣으면 플래그가 속한 단계 노드를 만들고 소스 → 명령어로 이어 붙인다. -f · -o · -P 값은 서브그래프로도 풀어 놓는다. 모르는 플래그는 아래 노트에 남는다.

그래프 JSON

파이프라인과 서브그래프 셋(포맷 · 출력 템플릿 · 저장 경로)을 통째로 주고받는다. 붙여넣고 불러오기를 누르면 현재 그래프를 덮어쓴다.

Anthropic API 키

서버가 없으므로 브라우저에서 api.anthropic.com 을 바로 부른다. 키는 이 브라우저의 localStorage 에만 있고 우리 쪽 어디로도 가지 않는다 — 다만 이 페이지의 스크립트는 읽을 수 있으니, 쓰고 버릴 키를 권한다. 키 없이 쓰려면 프롬프트 복사로 쓰던 LLM 에 붙여넣으면 된다.

프롬프트 복사

설치된 yt-dlp 를 리플렉션한 옵션 카탈로그가 통째로 들어 있다. 쓰던 LLM 에 붙여넣고, 돌아온 명령어를 명령어 칸에 붙여넣으면 검증은 똑같이 돈다.
