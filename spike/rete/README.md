# 스파이크 — Rete.js + lit 로 파이프라인 캔버스

본 앱의 캔버스 배관(와이어 렌더 · 포인터 제스처 · 팬/줌 · 팔레트 드래그, `app.js`
874줄 중 약 290줄)을 라이브러리로 대체할 수 있는지 재 본 것이다. **본 앱은 건드리지
않는다.** `src/core/` 와 `src/ui/bodies.js` 를 복사하지 않고 그대로 import 해서, "맞는다"는
답이 거짓이 될 수 없게 했다.

```
npm i
npx vite            # http://localhost:5210
node check.mjs      # 11가지 검사
```

## 결과: 11/11 통과

```
✓ 노드가 뜬다                          ✓ 노드 안 옵션 추가
✓ 본문이 우리 것이다                   ✓ 형제 노드는 x 위치가 플래그 순서를 정한다
✓ 포트가 붙었다                        ✓ 끊으면 우회로 표시된다
✓ 와이어가 그려진다                    ✓ 끊긴 노드에 bypass 클래스
✓ 명령어가 조립된다                    ✓ 콘솔이 조용하다
✓ 본문 편집이 명령어로 간다
```

## 되는 것

- **노드 본문 13종을 한 줄도 안 고치고 쓴다.** `bodyOf(n.type)(n)` 이 돌려주는
  TemplateResult 를 커스텀 노드 안에 그대로 꽂는다. `installBodies` 계약(다섯 가지)도
  그대로다.
- **`app.css` 가 노드에 그대로 먹는다.** 커스텀 노드를 light DOM 으로 만들면
  (`createRenderRoot() { return this }`) 전역 스타일이 닿는다. 보정이 22줄뿐이다.
- **우리 `state` 를 원본으로 두고 Rete 를 뷰로 쓸 수 있다.** Rete 이벤트를 `state` 로
  되돌려 쓰고 거기서 컴파일한다. `core/` 는 한 줄도 안 바뀐다.
- 위치가 뜻을 갖는 규칙도 얹힌다 — `nodetranslated` 에서 x·y 를 `state` 로 쓰면
  `livePath` 의 정렬이 그대로 산다.

## 대가 (여기서 실제로 물린 것들)

1. **`tpl.js` 를 `lit-html` → `lit` 으로 옮겨야 한다.** 플러그인은 `lit` 을 쓰는데 본 앱은
   `lit-html` 을 쓴다. 둘은 다른 패키지라 그대로 두면 "Multiple versions of Lit loaded" 가
   뜨고 TemplateResult·디렉티브를 서로 못 알아본다. (`tpl-lit.js` 가 그 대체본이다.)
2. **커스텀 노드는 템플릿이 아니라 LitElement 여야 한다.** 렌더러가 슬롯의 첫 엘리먼트에
   프로퍼티를 꽂고 `requestUpdate()` 를 부른다. 평범한 `<div>` 를 돌려주면
   `app.requestUpdate is not a function` 으로 죽는다. 타입만 봐서는 안 보인다.
3. **와이어는 `app.css` 로 못 꾸민다.** 연결은 플러그인의 `<rete-connection-wrapper>`
   안에서 그려지고 그 래퍼가 그림자 DOM 을 쓴다. 스타일을 컴포넌트가 직접 들어야 한다.
   (노드와 연결의 규칙이 서로 다르다.)
4. **초기 동기화와 사용자 조작을 갈라야 한다.** 그래프를 세울 때 나는
   `connectioncreated` 를 사용자 조작으로 받으면, 이미 `state` 에 있는 엣지라
   `connect()` 가 false 를 내고 방금 만든 연결을 도로 지운다. `syncing` 플래그가 필요하다.
5. **겹치는 순서를 손으로 잡아야 한다.** Rete 는 노드와 연결을 형제로 놓고 연결이 DOM
   뒤에 와서 노드 위에 그려진다.

## 크기

```
빌드 산출물     311KB  (gzip 71KB)   ← 스키마 blob 없이, 파이프라인만
본 앱 전체      229KB  (gzip 64KB)   ← 스키마 · 서브그래프 셋 · 검색 전부 포함
```

## 스파이크가 다루지 않은 것

서브그래프 셋(`-f`·`-o`·`-P`), 옵션 피커, 상단 검색, 명령어 읽기, 저장·복원,
그래프 JSON. 이것들은 라이브러리와 무관하게 그대로 남는다 — 그게 요점이기도 하다.
