# yt-dlp 스튜디오

yt-dlp 옵션을 **노드 그래프**로 조립한다. 의존성 없는 단일 HTML 파일 하나로 굽는다.

```
python build.py            # → dist/ytdlp-studio.html
```

브라우저로 그 파일을 열면 끝이다. 서버도, 번들러도, 네트워크도 필요 없다.

## 왜 노드인가

기존 버전은 9개 단계를 왼쪽 레일에 세워 두고 오른쪽에 옵션 폼을 뿌리는 형태였다.
문제는 폼이 **"이 실행이 어떤 순서로 무엇을 거치는지"**를 전혀 보여주지 못한다는 것이다.
191개 옵션이 평평한 목록으로 놓여 있으면 `--cookies-from-browser`와 `--embed-subs`가
실행 생애주기에서 완전히 다른 시점에 작동한다는 사실이 지워진다.

노드 캔버스는 그 층을 되살린다.

```
[source] ─→ [connect] ─→ [format] ─→ [process] ─→ [store] ─→ [command]
   URL         접속         포맷        후처리       저장        yt-dlp …
```

솔직히 말해 두자면, yt-dlp 명령어 자체는 DAG가 아니라 평평한 플래그 목록이다.
ffmpeg 필터그래프처럼 그래프가 *실행 의미*를 갖지는 않는다.
그래서 이 에디터는 엣지에 억지 의미를 붙이는 대신, 딱 하나의 규칙만 강제한다.

> **소스에서 명령어 노드까지 이어진 노드만 결과에 들어간다.**

와이어 하나를 끊으면 그 단계가 통째로 우회(bypass)된다. 옵션을 지우지 않고
"이번엔 빼고 돌려보기"가 되는, 폼에는 없던 조작이다. 끊긴 노드는 흐려지고
와이어는 점선이 되며, 하단 노트가 무엇이 빠졌는지 알려 준다.

## 조작

| 하는 일 | 방법 |
|---|---|
| 단계 노드 만들기 | 왼쪽 팔레트에서 캔버스로 드래그, 또는 클릭 |
| 옵션 넣기 | 노드 안 `+ 옵션` → 검색 → 선택 |
| 옵션 찾기 | 상단 검색(`/` 키). 고르면 해당 단계 노드에 자동으로 들어간다 |
| 잇기 | 노드 오른쪽 포트에서 다른 노드 왼쪽 포트로 드래그 |
| 끊기 | 와이어 클릭 |
| 노드 접기 | 헤더의 `▾`, 또는 헤더 더블클릭 |
| 노드 지우기 | 헤더의 `✕`, 또는 선택 후 `Delete` (앞뒤가 자동으로 다시 이어진다) |
| 화면 | 빈 곳 드래그로 팬 · 휠로 줌 · `화면 맞춤` |
| 되돌리기 | `명령어 읽기` — 기존 yt-dlp 명령어를 붙여넣으면 그래프로 복원한다 |
| 주고받기 | `그래프 JSON` — 그래프 전체를 복사/붙여넣기 |

플래그가 나가는 **순서는 그래프 순서를 따른다**(위상 정렬, 같은 층이면 x 좌표 순).
노드를 왼쪽으로 끌면 그 단계 플래그가 앞으로 나온다.

그래프는 `localStorage`에 자동 저장된다.

## 구성

| 파일 | 하는 일 |
|---|---|
| `gen_schema.py` | yt-dlp의 optparse 트리를 리플렉션해 `schema.json`으로 떨군다 |
| `schema.json` | 191개 옵션 · 9개 생애주기 단계 (yt-dlp 2026.07.04 기준) |
| `app.template.html` | 노드 에디터 본체. `/*__SCHEMA__*/{}` 자리에 스키마가 인라인된다 |
| `build.py` | 둘을 합쳐 `dist/ytdlp-studio.html` 하나로 굽는다 |

스키마는 help 텍스트를 긁는 게 아니라 옵션 객체를 직접 읽는다. yt-dlp를 올리면
스키마도 따라 올라간다. 릴리스마다 재실행할 것:

```
pip install -U yt-dlp
python gen_schema.py > schema.json
python build.py
```

손으로 정한 건 두 군데뿐이다. `gen_schema.py`의 **optparse 그룹 → 생애주기 단계**
매핑(16 → 9)과, `app.template.html`의 **한국어 의도 → yt-dlp 어휘** 사전(`KO`).
후자가 이 도구의 실제 부가가치다. "자막", "403", "이어받기" 같은 말로 검색이
걸리게 하는 층은 introspection이 절대 못 준다. 안 걸리는 말이 나오면 계속 채울 것.

## 알려진 제약

- 폰트를 Google Fonts CDN에서 가져온다. 오프라인에서는 시스템 모노스페이스로 폴백한다.
- `-f` 포맷 셀렉터(`bv*[height<=1080]+ba/b`)는 그 자체가 트리 구조지만, 여기서는
  아직 문자열 한 줄로 다룬다. 노드 서브그래프로 편집할 여지가 남아 있다.
- 그래프는 분기·병합을 허용하지만(순환은 막는다) yt-dlp에는 분기 실행 개념이
  없다. 갈라진 가지는 전부 같은 명령어로 합류할 뿐이다.
